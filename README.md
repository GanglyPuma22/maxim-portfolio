# Maxim portfolio prototype

Local-only first prototype for Maxim Mounier's portfolio site.

## What this is

A lightweight static site with a tiny Node server and a data-driven project model.

This first pass is designed to prove:
- a strong landing page
- featured flagship work first
- a reusable project detail page pattern
- a sane archive section for older work
- honest treatment of private or thin-source projects

## Run locally

From this directory:

```bash
npm start
```

Then open:

```text
http://127.0.0.1:4175
```

## Notes

- No deployment is included in this pass.
- Private projects stay intentionally high-level.
- The old tank demo guest credentials are intentionally not carried forward.
- Some media is still placeholder until a tighter screenshot/video pass happens.
